# 常见问题

## 打开后找不到窗口

SayType 是菜单栏应用。找屏幕顶部的波形图标，再打开设置或使用引导。菜单栏空间不足时，图标可能被其他图标遮住。

## 快捷键没反应

先在引导中检查麦克风和辅助功能权限，然后测试选定的键。Fn 可能已被系统用来切换输入法、显示表情或启动听写，也可能不被外接键盘上报；可改用右 Option。

重新编译或更新临时签名的 App 后，系统可能不再信任旧的辅助功能授权。退出 App，在系统辅助功能设置中移除旧条目，重新添加正在运行的 `SayType.app`，再启动。

## 识别不出文字

检查系统声音输入设备和麦克风权限。初次本机识别需要准备中文语言资源，可能发生联网下载。当前语言固定为中文。

可以先选“隐私优先”，在文本编辑的空白文档里试一句短话，区分本机识别问题和云端服务问题。

## 有文字，但没填进输入框

先点进可编辑区域再录音，并在填入完成前保持焦点。应用不支持直接写入时会尝试粘贴，仍失败时按状态条提示手动 `Cmd+V`。一些输入框不会向辅助功能接口暴露完整状态，自动填入并非总能读回验证。

云端文字稍晚覆盖本机结果，是逐段模式的迟到替换。若它在你的应用里选错文字，改用“一次填入”或本机模式，并报告目标应用和复现步骤。

## 云端一直退回本机

检查 Key、账号额度及所选模型是否支持相应接口。设置中的“测试连接”只测试文字整理，不证明语音识别模型也可用。具体模型服务由 OpenRouter 提供，名称可在自定义设置中修改。

## `xcrun` 找不到 SDK 或编译失败

需要 Xcode 26+，单独的 Command Line Tools 可能不包含所需 SDK。先打开 Xcode 完成首次组件安装，再检查：

```bash
xcodebuild -version
xcrun --sdk macosx --show-sdk-path
```

如果安装了多个 Xcode，可以仅对本次构建指定位置：

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer ./scripts/build.sh
```

## 反馈时提供什么

提供系统版本、芯片、目标应用、快捷键、识别/整理模式，以及操作后看到的状态。用不含私人内容的短句复现。日志、历史、录音和配置文件不需要默认上传。
