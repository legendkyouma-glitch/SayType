# SayType 说写

SayType 是一个 macOS 菜单栏语音输入工具。按住快捷键说中文，文字会经过整理，填入你正在使用的输入框。默认在本机识别，也可以接入 OpenRouter 做云端识别和润色。

**Apple Silicon · macOS 26+ · 中文界面 · MIT 开源**

**[直接下载 Mac 版，无需 Xcode](https://github.com/legendkyouma-glitch/SayType/releases/download/v0.1.1/SayType-0.1.1-macOS-arm64.zip)** · [版本说明](https://github.com/legendkyouma-glitch/SayType/releases/tag/v0.1.1)

[下载安装](#安装) · [怎么用](#怎么用) · [数据去向](docs/privacy.md) · [常见问题](docs/troubleshooting.md) · [参与开发](CONTRIBUTING.md)

## 能做什么

| 功能 | 当前支持 |
| --- | --- |
| 跨应用输入 | 通过辅助功能接口或剪贴板，把文字填入当前输入框；不会自动发送消息 |
| 录音方式 | 默认按住说话、松开结束；可以改成按一下开始、再按一下结束 |
| 输入节奏 | 默认边说边逐段填入；也可以说完后一次填入 |
| 文字处理 | 原样、轻度整理、云端润色；默认轻度整理，处理语气词、重复和标点 |
| 识别引擎 | macOS 本机识别，或自带 OpenRouter Key 使用云端模型 |
| 文字历史 | 在本机查看、复制和清空历史；可以关闭后续保存 |

这是一个早期版本，主要面向简体中文输入。目前没有长文编辑器、音频文件导入界面或通用多语言模式。其他应用能否直接填入，取决于它们的输入框实现；无法直接写入时可手动粘贴。

## 安装

普通用户直接下载 App 就能使用，**不需要 Xcode、下载源码或运行终端命令**。本机识别也不需要 API Key。

1. [下载 SayType-0.1.1-macOS-arm64.zip](https://github.com/legendkyouma-glitch/SayType/releases/download/v0.1.1/SayType-0.1.1-macOS-arm64.zip)，双击解压。
2. 把 `SayType.app` 拖进“应用程序”文件夹，再双击打开。
3. 按首次引导授予麦克风和辅助功能权限，选好快捷键后试说一句。

当前发布包已使用 Developer ID 正式签名，并通过 Apple 公证，公证票据随 App 一起打包。首次打开时按 macOS 提示确认即可。

从 0.1.0 更新时，签名身份发生变化，可能需要重新授予辅助功能权限。

需要修改代码或自己编译时，再看 [开发说明](CONTRIBUTING.md#构建与签名)。

## 第一次试用

1. 打开 App，按引导选择“隐私优先”。本机识别不需要 API Key；首次使用可能需要联网下载系统语言资源。
2. 授予麦克风和辅助功能权限。系统确认需要由使用这台 Mac 的人完成。
3. 选择 **右 Option** 或 **Fn** 快捷键。引导会根据系统设置推荐一个。
4. 打开“文本编辑”并点进空白文档。按住快捷键，说“明天下午三点开会，讨论一下新版本的上线计划”，然后松开。
5. 检查文字是否出现在光标处。屏幕底部会显示录音、处理和填入状态；如果提示手动粘贴，按 `Cmd+V`。

SayType 运行在菜单栏，没有常驻 Dock 窗口。设置、历史和退出入口都在菜单栏的波形图标里。

## 怎么用

| 操作 | 按住说话（默认） | 按一下开始（可选） |
| --- | --- | --- |
| 开始 / 结束 | 按住开始，松开结束 | 按一下开始，再按一下结束 |
| 松手继续说 | 按住快捷键时再按空格锁定；再按快捷键结束 | 已经是免按住的模式 |
| 取消 | `Esc`；已填入的分段文字不会撤回 | 同左 |

所有模式单次最长 **5 分钟**。锁定或切换录音时，持续静音 30 秒会自动结束。填入后可以继续编辑，也可以尝试在目标应用中用 `Cmd+Z` 撤回。

录音方式、输入方式和整理力度都可以在设置中调整。“原样”仍会把繁体字转为简体字；润色需要云端整理，并自动改为一次填入。

轻度整理和润色还支持“换行”“新段落”“另起一段”口令。快捷键目前只支持右 Option 和 Fn，不能设置任意组合键。

## 可选：云端识别和整理

菜单栏图标 → 设置 → **OpenRouter Key**，保存自己的 Key，再选择“效果优先”。在 App 里保存的 Key 写入 macOS 钥匙串；保存时会发起一次简短的文字整理请求测试连接。

| 预设 | 音频识别 | 文字整理 |
| --- | --- | --- |
| 隐私优先 | 本机 macOS 识别 | 本机规则 |
| 效果优先 | OpenRouter 云端模型 | OpenRouter 云端模型 |
| 自定义 | 可分别选择 | 可分别选择 |

没有 Key 时使用本机识别和规则整理。在“自定义”中也可以改模型名称。默认识别会**同时**把每段音频发给 `qwen/qwen3-asr-1.7b` 和 `openai/gpt-4o-mini-transcribe`，采用先成功的结果；两路请求都可能产生费用。默认整理模型是 `google/gemini-2.5-flash-lite`。模型是否可用及费用取决于你的 OpenRouter 账号和服务商。

云端识别等待超过约 4 秒时，会先采用本机结果；这不是文字一定在 4 秒内填入的保证。逐段模式下，晚到的云端结果可能替换刚填入的本机文字。部分应用只能用模拟选中和粘贴，无法核对原文，因此请检查替换结果。选择本机模式或一次填入可以避开这种迟到替换。

云端整理会发送待整理文字、本次口述前文的末尾和当前应用名。整理失败或返回明确截断的结果时，会退回本机规则；模型仍可能改错或遗漏内容，尤其是较长的输入。完整说明见 [数据与隐私](docs/privacy.md)。

## 使用前需要知道

- 当前识别语言固定为中文；英文术语可能被识别，但不是独立的多语言识别模式。
- 应用兼容性尚未全面验证。焦点改变、输入框无法读取、剪贴板工具干预，都可能影响填入或替换。
- 文字历史默认开启，最多 500 条；加载及保存时会删除超过 30 天的记录。关闭保存不会删除已有历史，需另点“清空全部”。
- App 不主动保存音频文件。本机处理、云端请求、剪贴板和日志的区别见 [隐私说明](docs/privacy.md)。
- 没有公开的 CLI / MCP 产品接口。仓库里的 `--selftest` 是开发诊断工具，不能作为稳定的转录 API。

如果你把这个仓库交给 Agent 帮忙安装，直接让它按“安装 → 第一次试用”的步骤操作即可。功能和使用方法都在这份 README 中；系统授权和实际试说仍需要你参与。
