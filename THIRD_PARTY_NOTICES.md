# Third-party software and model downloads

SayType includes native libraries from these projects. The corresponding license
texts from the pinned source checkouts are included in `ThirdPartyLicenses` in
the built application's Resources folder.

- MLX Audio Swift, Copyright © Blaizzy and contributors — MIT.
  https://github.com/Blaizzy/mlx-audio-swift (0.1.3)
- MLX Swift / MLX / MLX C, Copyright © Apple Inc. and contributors — MIT.
  https://github.com/ml-explore/mlx-swift
- MLX Swift LM, Copyright © Apple Inc. and contributors — MIT.
  https://github.com/ml-explore/mlx-swift-lm
- Swift Transformers, Copyright © Hugging Face and contributors — Apache-2.0.
  https://github.com/huggingface/swift-transformers
- Swift Hugging Face and Swift Jinja — Apache-2.0.
  https://github.com/huggingface/swift-huggingface
  https://github.com/huggingface/swift-jinja
- Other transitive package licenses are included with their package names.

Model weights are downloaded only when requested in Settings and are not
included in this application or repository. Qwen3-ASR models are distributed
under Apache-2.0; OpenAI Whisper models are distributed under MIT. Custom model
repositories retain their own licenses. Model repository links are shown in
Settings. No remote Python code is downloaded or executed.
